# Quantii Local — instaladores

Este repositorio sólo guarda los instaladores publicados de **Quantii Local**, la app del PC del restaurante que imprime y atiende la operación cuando se cae internet.

- Descárgalo desde Quantii: **Configuración › Restaurante › Impresión › Quantii Local**.
- O desde [la última versión](https://github.com/ATID-Solutions/quantii-local-releases/releases/latest): Windows (.exe), macOS (.dmg, Apple o Intel) y Linux (.AppImage o .deb).

La app instalada se actualiza sola desde aquí (en macOS avisa y se descarga a mano).

El código no está en este repositorio.
